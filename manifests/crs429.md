# CRS-4.29.0 attack generation and co-evolved-rule replay

Maps the second-revision CRS-4.29.0 experiments to their released files. The attack agent is run
directly against the current OWASP CRS 4.29.0 (paranoia level 1), and the frozen co-evolved rules
(learned only on CRS 3.3.2) are replayed against the held-out attacks that bypass CRS 4.29.0.
Supports the manuscript tables `tab:crs429-gen`, `tab:crs429-cg-sqli`, and `tab:crs429-cg-xss`, and the
CRS-4.29.0 side of the PL2 table `tab:r23-pl2` (see `manifests/pl2.md`). Related: `manifests/updated_crs.md`
(R1.3 persistence of CRS-3.3.2 bypasses under CRS 4.29.0).

## Attack generation (`tab:crs429-gen`)
`results/crs429_generation/` -- GPT-4.1-mini attack agent, five independent runs x ten rounds, on the
six custom-application pages.
- `crs429_generation_summary.csv` -- per page: generated / execution-valid counts and the CRS-4.29.0
  bypass rate (mean +/- SD and 95% CI over the five runs), false-bypass total.
- `crs429_generation_rounds.csv` -- per page x run x round counts (generated, validated, non-403 bypass,
  confirmed, distinct). `analysis/crs429_generation.py` recomputes the table from these.
- Bypass rate 78.0-87.8% (SQLi), 93.8-99.6% (XSS); 0 false bypasses.

## Co-evolved-rule replay against CRS-4.29 bypasses (`tab:crs429-cg-sqli` / `tab:crs429-cg-xss`)
`results/crs429_cg/` -- per (page, held-out attack seed) block-rate matrix over the ten defense seeds,
for CG-Static and CG-Adaptive. Held-out attackers: custom pages = Claude Opus 4.7 (model shift),
bWAPP/Juice Shop = Llama-4 Maverick (cross-backend).
- `crs429_cg_sqli_matrix.csv` -- SQLi, rules evaluated with CRS 4.29.0 deployed (cross-backend
  micro-average CG-Adaptive 100.0% / CG-Static 94.1%).
- `crs429_cg_xss_matrix.csv` -- XSS, rules in isolation (CRS disabled) because CRS 3.3.2 catches many of
  these; macro-average CG-Adaptive 91.4% / CG-Static 90.9%.
- `analysis/crs429_cg_replay.py` reproduces both tables.

## Notes
- All released files are aggregate / per-seed derived counts and rates; no attack payloads. The raw
  CRS-4.29-bypassing confirmed-bypass corpora (`*_confirmed_bypasses_PRIVATE.txt`) are withheld; a
  representative subset is hashed in `manifests/provenance_checksums.csv`, together with the four
  CRS-4.29 attack-prompt modules.
