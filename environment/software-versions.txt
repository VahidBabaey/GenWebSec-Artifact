GenWebSec -- exact software versions
====================================

Every value below was read from the live experimental host, not transcribed from
the paper. The command used is shown with each group so the record can be
re-derived. Collected 2026-09-14.


1. OPERATING SYSTEM
-------------------
  Distribution        Ubuntu 22.04.5 LTS (Jammy Jellyfish)
  Kernel              6.6.87.2-microsoft-standard-WSL2
  Kernel build        #1 SMP PREEMPT_DYNAMIC Thu Jun  5 18:30:46 UTC 2025
  Platform            WSL2 on Windows 11

  The kernel is pinned rather than stock. The stock WSL 6.18.x kernel deadlocks
  on per-VMA locking during process fork and teardown, which wedged Apache on
  reload-heavy defense runs. The pinned kernel 6.6.87.2 was extracted from the
  official WSL 2.5.10 msixbundle and selected in .wslconfig. See hardware.md.

  Commands: cat /etc/os-release ; uname -r ; cat /proc/version

4. BROWSER (XSS validity oracle)
--------------------------------
  Chromium            150.0.7871.128     (snap package, revision 3499)
  ChromeDriver        bundled with that snap revision, so versions match exactly
  ChromeDriver path   /snap/chromium/current/usr/lib/chromium-browser/chromedriver
  Size                28,107,496 bytes

  /usr/bin/chromedriver is a 312-byte shell wrapper that execs the snap binary.
  The XSS oracle drives Chromium through Selenium and confirms a payload only
  when the expected JavaScript dialog is observed.

  Commands: cat /snap/chromium/current/meta/snap.yaml
            readlink -f /snap/chromium/current

--------------------------------------------
  Docker              29.1.3   (build 29.1.3-0ubuntu3~22.04.2)

  symlink hijacks the CLI. iptables is switched to the legacy backend, because

7. REVERSE-PROXY LAYOUT
-----------------------
  Apache listens on port 80 and proxies to each backend. ModSecurity inspects
  every request at the proxy, before it reaches any application, so all three
  targets are evaluated under one identical WAF configuration. HTTP 403 denotes
  a WAF block.

      http://localhost/customapp/  ->  http://127.0.0.1:8080/    SQLi application
      http://localhost/juice/      ->  http://127.0.0.1:3000/    OWASP Juice Shop
      http://localhost/bwapp/      ->  http://127.0.0.1:8082/    bWAPP

  Committed as configs/modsecurity/00-genwebsec-proxy.conf.

  Commands: cat /etc/modsecurity/custom/00-genwebsec-proxy.conf
            grep Listen /etc/apache2/ports.conf


8. GENERATED-RULE INCLUDE
-------------------------
  Include directive   IncludeOptional /etc/modsecurity/custom/*.conf
                      (from /etc/apache2/mods-enabled/security2.conf)
  Rule file written   /etc/modsecurity/custom/sft_rule.conf
  Written by          helpers/modsec_helpers.py

  The defense agent's accepted rules are written to that single include file.
  An empty file is the CRS-only baseline condition. Before any reload the
  harness runs the Apache configuration test, and a candidate that fails the
  test is discarded rather than deployed.

  The filename is a historical artifact of an earlier project and does not
  indicate anything about the rules it holds.

  Commands: grep -rn Include /etc/apache2/mods-enabled/security2.conf
            grep -rn DEFAULT_RULE_PATH helpers/modsec_helpers.py


9. MODELS AND API
-----------------
  Interface           OpenRouter v1 chat-completions
  Client              OpenAI Python SDK 2.8.0

  Routing identifiers as written in the experiment code:

    openai/gpt-4.1-mini          hardening attack agent, hardening defense agent,
                                 and baseline attack generator
    anthropic/claude-opus-4.7    held-out attacker on the controlled applications
    meta-llama/llama-4-maverick  held-out attacker for cross-application transfer

  These are provider routing identifiers. OpenRouter does not expose immutable
  provider snapshot hashes, so no snapshot identifier can be recorded. This is a
  genuine limit on exact reproducibility of model behaviour, not an omission.

  Generation parameters are recorded with the experiment configuration in
  configs/experiment/.

  Command: grep -rhoE '"(openai|anthropic|meta-llama)/[A-Za-z0-9._-]+"' WorkFlowV2/*.py


10. WHAT IS NOT USED
--------------------
  conda               Not used. The doc's suggested conda-environment.yml is
                      therefore absent by design; environment/requirements.txt is
                      the equivalent and is a real pinned freeze of the
                      virtualenv actually used.
  sqlite3 CLI         Not installed; SQLite is used only through Python.
  Docker Desktop      Deliberately disabled in favour of the native daemon.
